## Pasarelas de pago — verificar desde Venezuela
| Opción | Funciona con dueño en Venezuela | Nota |
|---|---|---|
| PayPal | **Sí (confirmado)** | Cuenta comercial que ya recibe pagos. Pasarela principal. Puede retener fondos a vendedores nuevos. |
| Shopify Payments | No | Exige SSN/EIN y banco de EE. UU. (solo con una LLC en EE. UU.). |
| Stripe | No | Venezuela no está soportada. |
| 2Checkout / Verifone | Verificar | Pasarela de Shopify que acepta comerciantes de muchos países; tiene revisión de cuenta. |
| Payoneer | No como checkout | Sirve para **recibir** pagos y retirar; Venezuela soportada. No es pasarela directa del checkout de Shopify. |
| Wise | No como checkout | No es pasarela de Shopify; además Wise suele no abrir cuentas a residentes de Venezuela. Verificar. |
| Cripto (Coinbase Commerce, NOWPayments, BitPay) | Sí | Sin banco. Pocos clientes de EE. UU. pagan así. |
| Pago manual (Zelle, Binance Pay, Zinli) | Sí | Gratis, se crea en Configuración → Pagos → Métodos manuales. Baja confianza y conversión. |

Las pasarelas locales (Instapago, Pagoflash, Banesco) cobran en bolívares a venezolanos: no sirven para clientes de EE. UU.
